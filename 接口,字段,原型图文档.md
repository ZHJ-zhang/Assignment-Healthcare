>

## 一、通用规范

### 1.1 分页请求参数

| 参数      | 类型   | 必填 | 说明                |
| :-------- | :----- | :--- | :------------------ |
| pageNum   | int    | 是   | 页码，从1开始       |
| pageSize  | int    | 是   | 每页条数，默认10    |
| keyword   | string | 否   | 模糊搜索关键字      |
| startTime | string | 否   | 开始时间 yyyy-MM-dd |
| endTime   | string | 否   | 结束时间 yyyy-MM-dd |

### 1.2 分页返回结构

json

```
{
  "code": 200,
  "msg": "success",
  "data": {
    "total": 100,
    "pageNum": 1,
    "pageSize": 10,
    "list": []
  }
}
```



### 1.3 状态码约定

| code | 说明       |
| :--- | :--------- |
| 200  | 成功       |
| 400  | 参数错误   |
| 401  | 未登录     |
| 403  | 无权限     |
| 500  | 服务器异常 |

| 方法   | 路径                             | 说明      |
| :----- | :------------------------------- | :-------- |
| POST   | /api/system/user/login           | 登录      |
| POST   | /api/system/user/logout          | 登出      |
| GET    | /api/system/user/page            | 用户分页  |
| POST   | /api/system/user                 | 新增用户  |
| PUT    | /api/system/user/{id}            | 修改用户  |

| GET    | /api/system/dept/tree            | 科室树    |
| GET    | /api/system/log/page             | 日志分页  |

**公共下拉选项（登录即可，不走按钮级权限）**

| 方法 | 路径                        | 说明                             |
| :--- | :-------------------------- | :------------------------------- |
| GET  | /api/common/options/depts    | 科室选项（id / deptName）        |
| GET  | /api/common/options/doctors  | 医生选项（id / realName / deptId）|
| GET  | /api/common/options/drugs    | 药品选项（id / drugName / spec / unit / salePrice）|
| GET  | /api/common/options/patients | 患者选项（id / name / patientNo / gender）|

> 开方、挂号、接诊、收费都离不开科室/医生/药品/患者选项，而它们的
> `/system/dept/list`、`/system/user/page`、`/drug/page` 属于管理员权限，医生直接调会被 403 挡掉，
> 页面表现为「无权限」且下拉全空。这组接口只要求登录，且只返回挑选字段，
> 不带用户密码、患者身份证与手机号。

**登录接口示例**

json

```
// 请求 POST /api/system/user/login
{ "username": "admin", "password": "123456" }

// 响应
{
  "code": 200,
  "msg": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1...",
    "userInfo": { "id": 1, "realName": "管理员", "roleCode": "admin" }
  }
}
```
